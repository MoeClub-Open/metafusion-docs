# 更新日志

## 2026-10-11 — 提交、来源与服务额度

- [工作副本与提交](/api-commits)记录 checkout、原子批次、三方合并、预览与持久回执；创建和身份更新都需复核候选，原始请求裁剪不影响长期幂等恢复。
- [云端 MCP](/api-mcp)提供 OAuth 连接与平台工具；默认只预选读取权限。新 PAT 和 MCP 授权不下发通配或 `.manage` 管理权限，既有凭据不自动吊销。
- [目录限流](/api-overview#限流)改为读写合计共享 180 次/分钟，多副本共用数据库窗口；管理员默认豁免可由账号或组策略收回。互动额度与私信策略使用自己的[治理端点](/api-community#限流策略)，账号登录失败保护使用共享计数。
- 新证据拒绝 `self` 和本站自身页面，未改变的历史来源保留；导入不再生成无来源的本站证据。图片、外部标识与隐藏收录写入边界见[新建与编辑](/api-edit)。
- 补齐[自托管封面](/api-storage#自托管封面)的摘要、上传、完成、绑定与有序图片流程，并在能力索引登记提交端点与错误恢复入口。
- 启用目录与存储生命周期同步时，合并迁移全部文件用途，删除撤除完整身份集合的绑定；下架草稿和调整收录保留文件。已完成资产最后解绑后默认保留 7 天，到期由运维 worker 回收，见[目录变更与资产保留](/api-storage#目录变更与资产保留)。

## 2026-10-07 — 合并重复文档入口

- 理念归入平台概览；标签、货架与多语言归入目录教程；投稿、编辑与审查统一为一篇指南。
- Agent 技能安装与工具使用归入 Agent 页面；认证、写入和 OAuth 管理协议分别维护，不再复制完整说明。
- 删除五篇重复源页面，更新站内引用；旧公开地址提供轻量浏览器跳转，不再保留旧正文或导航项。

## 2026-10-06 — 文档分层与查询契约

- 用户入门、编辑与投稿说明按操作步骤整理；字段、动态配置与社区协议归入独立参考页。
- 统一关系查询覆盖固定结构、语义关系及 definitions 声明的嵌套实体引用，分页与遍历边界见[实体查询与详情](/api-entities)。
- 接口参考纠正权限、持久幂等、严格分页和账号限流说明，索引搜索的计数与 cursor 契约见[检索](/api-search)。
- 导航检查覆盖首页入口、正文页面与实际标题锚点，构建拒绝死链。

## 2026-10-03 — 媒体编目与编辑流程

- 发行版本、CD/BD/黑胶、小说章节与动画分集按八实体骨架记录，独立歌曲和录音可以跨发行复用。表达组合、显式版本组与单条收录编辑见[元数据目录教程](/catalog)。
- 整个条目编辑器按基本信息、归属与收录、附加信息、图片与标识、关系、说明与来源分区，切换保留同一份草稿。
- 模板自动选择采用显式条件和优先级，不按已填字段猜类别；字段、词表、关系约束与受支持展示区块可通过 definitions 管理。说明见[实体模型与字段](/frbr-model)。
- 对比页修复缓存恢复时选中状态循环，单个已选条目加载真实题名与封面。
- 精简重复的历史接口说明，检索匹配范围统一参考[检索](/api-search)；升级、迁移与恢复流程在代码仓开发文档维护。

## 2026-10 — 检索与服务入口

- 关键词正式使用 OpenSearch，数据库复核当前可见性与精确筛选；索引不可用返回 503，深页使用 PIT cursor。索引快照计数与错误处理见[检索](/api-search)。
- 规范实体详情入口为 `/catalog/{id}`，顶栏提供统一搜索入口，目录首页为 `/home`。
- 账号、互动与存储通过同域网关聚合；接口归属和认证方式见[API 概览](/api-overview)与[认证与凭证](/api-auth)。

## 2026-09-23 — 公开实体资源读取

公开实体绑定的原始文件可匿名读取；上传与绑定仍需登录，资源访问以实体可见性和资源状态判定。接口与限制见[存储上传与下载](/api-storage)。

## 2026-09-19 — 站内通知

上线收件箱、未读角标、已读操作与事件聚合，通知只对收件人可见。当前保留期不自动删除业务通知，评论回帖成功不依赖通知投递成功。

## 2026-09-18 — PAT 与目录限流头

账号服务支持个人访问令牌，权限取签发者当前拥有的权限码；目录路由限流返回额度与重试响应头。现行认证、吊销时效和限流范围见[认证与凭证](/api-auth)。

## 2026-08-21 — 独立文档站

上线模型、共建规范、API 与站务说明，以及正文检索和移动端导航。文档站内容以本仓库为源；开发实现与部署契约在 [MetaFusion](https://github.com/MoeclubM/MetaFusion) 主仓维护。
