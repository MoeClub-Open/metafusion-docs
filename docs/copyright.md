# 版权与 DMCA

## 1. 基本原则

- MetaFusion 是资源收录与编目平台，**不鼓励亦不支持侵权分发**。
- 平台不做转码与在线预览，只分发原档；访问按绑定实体可见性判定，上传者与审核者可直读，公开实体绑定的文件可匿名读取。
- 元数据（事实性信息、结构化描述）与媒体二进制（受版权保护的文件）适用不同规则：前者开放，后者受控且需合规使用。

## 2. 提交保证

- 你保证拥有提交内容的必要权利，或属于合理使用、公共领域、已获授权。
- 可在支持的资料字段中补充出处与署名，提交说明写在 commit message。来源记录不作为编辑或合入的强制门槛；内容权利仍由提供者负责。

## 3. 侵权投诉（DMCA 风格）

若你认为站内内容侵犯你的版权，可以走**站内举报**（推荐）：在实体 / 资源 / 短评 / 帖子页面点「举报」，理由选**侵权**，说明里写清权利人身份与联系方式，证据链接填权属证明 URL。
举报内容**只有处理人可见**（不会像发帖那样公开），站务按 [社区使用指南](/community-guide) 的「举报与申诉」受理与处置；也可以用[联系方式](/contact)里的渠道提交。

一份完整的侵权投诉应包含：

- 权利人身份与联系方式
- 被侵权作品的描述与权属证明
- 侵权内容在站内的具体 URL（Work/Release/Asset ID 与链接）
- 声明“善意相信该使用未经授权”与“信息准确、愿承担伪证责任”

站务将在核实后下架或限制访问（处置结论记在举报队列里，动作码 `report.resolved`），并通知上传者。

## 4. 反通知

上传者（被处置方）若认为下架有误，可在「我的举报」里对那条处置提交**一次**申诉（说明权属或合理使用依据），站务在管理台的「申诉队列」复核后给出采用或驳回结论。

需要说明的是：**采用申诉只记录结论**，不会自动恢复已下线的内容——恢复是另一次内容操作（重新上传 / 重新发布），不与其他用户的举报记录混在一起。

## 5. 重复侵权

重复侵权或恶意投诉的账号将被限流或封禁，邀请链将作为溯源依据之一。

## 6. 技术措施

- `robots.txt` 允许抓取公开页面，不承担访问控制；限流用于防止滥用。媒体读取权限见上方绑定实体可见性规则。
- 速率限制与访问日志用于防止批量外泄
