# 资源上传与下载

资源文件与元数据词条分别管理。主站仅托管词条 `pictures[]` 位图素材（封面、封底、手册内页、盘面、侧标、包装等），不存储作品本体；音频、视频、光盘镜像与电子书仅在独立资源站提供。

## 上传前

1. 确认你有权上传和提供该文件。
2. 查找或补齐对应作品、表达或发行的词条，核对版本。
3. 保持原始文件与原始质量，填写能说明内容和用途的文件名。
4. 准备能核对内容、版本和使用依据的来源。补建词条时按[词条编辑与审查规范](/editing-guide)填写。

## 文件质量与格式

保持原始内容和质量，不为符合推荐格式而重复转码。以下格式供选择工具时参考，不是上传白名单：

| 内容 | 常见格式 |
| --- | --- |
| 无损音频 | FLAC、ALAC、WAV |
| 有损音频 | MP3、AAC |
| 视频 | MP4、MKV |
| 图书与漫画 | EPUB、PDF、CBZ、CBR |
| 目录图片 | JPG、PNG、WebP、AVIF、GIF |

封面保持原始比例，不拉伸或为了卡片裁切。官方图源不自动意味着允许转载；权利不明时不上传或引用。投稿元数据不要求同时提供文件。

## 上传与绑定

使用界面提供的上传入口。客户端会计算文件指纹，已有相同内容时复用文件，避免重复存储；大文件可以分片上传。

上传完成后，按实际用途绑定到正确词条，例如原档、音轨、光盘镜像或扫描资料。可读取别人的已有文件不等于有权新增绑定；文件已经存在也不代表它已绑定到你的目标，完成后请回到词条核对资源入口。

上传与绑定需要登录及相应权限。开发者的初始化、上传、完成和绑定协议见[存储上传与下载](/api-storage)。

## 下载与可见性

文件完成上传后，上传者与具有存储审核权限的人可以直接读取。其他人还需文件未被禁发，并且至少一个绑定词条对自己可见。满足条件的公开词条文件支持匿名访问；未完成或不可见文件会显示为不可用。

通过页面提供的资源入口下载。临时下载地址有有效期，失效后重新获取即可；长期引用图片或文件时应使用稳定的内容入口。

## 原始文件的使用

平台提供原始文件，不生成转码后的预览流。音频、视频、图书等内容请交给合适的播放器或阅读器打开。文件与条目版本不符时，先核实来源，再纠正绑定或资料。
