# AI 助手与生成介绍

站点启用 AI 后，可以让助手查询词条、梳理关系、核对公开资料，或按你的要求提交修改。助手使用当前账号的权限；聊天不会额外申请 API Key 或 MCP 授权。

## 查询、编辑与后台运行

登录后从顶栏打开「AI 助手」（`/assistant`），选择站点模型或本人添加的自备模型，并可按需在模型选择器旁切换思考强度（默认、关闭、极低、低、中、高、超高），描述问题或修改要求。页面的「问答」「自主任务」「自备 API」「用量记录」分别管理单对话问答、后台自主探索任务、自备服务商与模型以及消耗记录。桌面在左侧切换会话；手机点击会话按钮打开左侧抽屉，选择后自动关闭，也可点遮罩或关闭按钮返回。可以直接附上词条链接、编号和来源，例如：

```text
查询 UMCK-1766 对应发行版，说明发行主体、收录内容和关联作品。
如果发行资料缺少我提供的官方来源中的编号，请核对当前记录后补充；保留作品或发行版的原始名称。
```

发送提问后，请求会在服务端后台持续执行，多轮工具调用进度与已生成的消息会实时保存。运行期间可以随时切换其他对话、新建对话、查看用量或离开当前页面；重新打开对话时会自动显示当前执行状态、工具步骤及最终回答。正在后台执行的对话在侧栏显示运行标记，完成后才允许删除。

查询会读取当前目录和关系，外部来源只作为资料。编辑在服务器工作副本中进行，多次操作可形成 commit，再按你的指令 push，无需逐次确认授权。普通账号发起 PR，有免审权限的账号可直接合入；来源与查证记录可省略。查看助手返回的实际提交和合入结果，回答文字不能代替状态。

对于「完善某个企划或系列相关数据」这类跨多条目的范围目标，可以在「自主任务」页设定目标范围、积分预算、并行子任务上限及规划/执行模型与思考强度（或在对话中直接让助手创建自主任务）。对话主助手仅用于与你交互，不常驻空跑；后台自主任务由规划器（Planner）根据目标和预算维护计划，并将目录盘点（recon）、来源查证（research）、工作副本编辑（edit）与变更复核（review）派发给独立的子代理（Worker）执行，支持随时补充方向指令、暂停、恢复或停止。

模型可能理解或引用错误。原始来源、结构化记录和修订历史仍用于核对事实；AI 的回答本身不能充当录入来源。助手不会因为资料缺少封面、署名或评分而要求先补齐整个词条。

## 积分与 token 用量

使用站点提供的模型时，按模型的输入、输出 token 费率消耗积分。一次问答可能包含多轮查询和模型调用，显示的用量是本次请求累计值。调用前会预留积分，结算后释放未使用的部分；余额不足或平台预算用尽时停止新的调用。

输入框底部直接选择模型并显示同一个积分余额。上下文指示包含当前系统提示、已保存会话、未发送的输入和工具定义，使用与运行时一致的保守估算上界；可展开查看消息、工具数量和回答预留量。它描述当前上下文上界，独立于多轮调用累计的计费 token。

积分来自：

- 注册赠送：首次访问 AI 账户时发放，每个账号一次。
- 编辑采纳：奖励生效时间之后，已批准或免审且实际应用的提交，每个提交一次；待审、拒绝和未应用的提交不发放。
- 管理员调整：后台带说明增减积分，保留流水。

赠送数量和模型费率由站点配置。当前不提供赞助支付或自动充值。平台预算以美元成本管理，用户积分是独立额度，两者没有固定兑换关系。

用量记录包括输入、输出和缓存输入 token、扣除积分及调用状态。若上游超时或中断后无法确认实际消耗，记录为 `unknown`，并以 `usage_estimated=true` 标明保守估算；这不表示调用成功，也不应直接重复发送同一修改。

## 使用自己的 API（BYO）

在「自备 API」页按「自备服务商」与「自备模型」两层管理个人配置。先添加服务商，填写名称、接口格式、公开 HTTPS API 根地址和密钥：

| 接口格式 | 根地址示例 | 调用路径 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1` | `/chat/completions` |
| OpenAI Responses | `https://api.openai.com/v1` | `/responses` |
| Anthropic Messages | `https://api.anthropic.com/v1` | `/messages` |
| Gemini GenerateContent | `https://generativelanguage.googleapis.com/v1beta` | `/models/{model}:generateContent` |

其他服务商按它实际实现的格式选择，根地址保留服务商要求的版本路径。接口格式显式配置，失败不会自动换格式或再次调用。密钥加密保存，只显示是否已配置与末尾提示，可以改名、替换、停用或删除。管理员可管理元数据记录，无法读取完整密钥。

添加服务商后，可在「自备模型」中为该服务商添加多个模型，分别设置显示名称、上游模型标识、上下文窗口、最大输出 token 和最大输出参数名（`max_tokens` 或 `max_completion_tokens`），无需站点预先配置同名模型。启用后的自备模型会直接出现在问答、条目介绍生成及自动维护的模型选择器中（标注 `自备 API`）；选择后消耗 0 平台积分，仍记录 token 用量，上游账单由服务商结算。删除服务商前需先删除其关联的自备模型。

会话和用量记录保存在站点，模型提供方会收到本轮对话及完成请求所需的资料。不要把无关凭据或私密信息填进提问或来源内容。

## 词条中的生成介绍

词条正文区域可选择平台模型或自备模型生成结构化介绍，平台模型按费率消耗积分，自备模型由上游服务商计费。已有有效缓存时直接读取，不重新调用模型，也不重复扣费；访问页面不会自动触发生成。

生成内容可以包含说明文字、关系与字段表格、时间轴和数据图。表格、时间轴和数据图由服务端从公开结构化事实生成，说明文字由模型生成。每份内容保留来源条目与生成信息。资料范围被截断时会标明不完整。

缓存会校验条目、邻接关系与引用实体、definitions、语言和模型配置的事实指纹。资料变化后不会继续把旧内容作为当前介绍，可重新生成。使用平台模型生成的介绍可共享读取；使用自备模型生成的缓存仅对本人显示。生成介绍不会覆盖人工维护的正文或直接新增目录事实。

## Wikipedia、萌娘百科与公开来源

助手和 MCP 可以读取站点配置的公开来源及 MediaWiki API，保留原文、抓取时间、内容哈希、署名和许可说明。Wikipedia、萌娘百科或自定义站点的可用性由其公开接口决定；访问被拒绝时显示失败，不绕过限制。

外部百科内容不会自动覆盖词条。需要录入其中的事实时，仍通过工作副本与提交录入，并遵守来源的署名和许可要求。网络请求及 MCP 参数见[云端 MCP](/api-mcp)，程序接入见[AI 助手 API](/api-assistant)。

## 网页搜索

问答输入框的「搜索设置」可选择搜索服务，以及 DeepSeek 搜索使用的个人「自备服务商」。DuckDuckGo 默认启用且免费，返回网页搜索结果；读取正文仍可使用普通网页抓取。DeepSeek 使用官方原生 Search 与 Fetch 接口，支持搜索并直接获取正文。搜索结果及网页仅作为参考资料。

平台搜索按后台设置的每次成功请求积分收费，HTTP 200 且有结果才扣费；空结果及明确失败不扣费。无法确认结果的超时或中断会标为 `unknown` 并保守结算该次预留，后台可查，不自动重发。选择自备服务商时复用「自备 API」中本人启用的服务商密钥（地址填 `https://api.deepseek.com` 或 `https://api.deepseek.com/v1`），消耗 0 平台积分，上游费用由用户自行结算。

## 自动维护

管理员在后台自动维护页管理定时主 Agent。系统先通过数据库查询检查待办，有任务才启动主 Agent；主 Agent 按任务类型创建审核、查证和修复子 Agent，没有待办任务时不调用模型。对话页左侧选择主 Agent 运行记录，上方切换主、子 Agent，查看任务、工具调用、用量和实际提交。输入框用于布置维护任务；停用或暂停期间任务保留在队列中。

设置中可分别选择主模型、子模型（支持站点模型或管理员本人的自备模型）、检查间隔、每轮子 Agent 上限、每小时子任务上限、月积分额度以及搜索服务与搜索自备服务商。平台费用记服务账号；保存自备模型或自备服务商配置的管理员授权使用自己的对应连接，目录修改作者保持不变。

资料修复通过工作副本提交。待合入 PR 由独立只读审核子 Agent 检查，服务账号自己的 PR 不参与自动审核。默认审核只给建议；显式开启自动合入高置信审核结果后，服务器才会重新校验冻结版本并合入。重启会恢复未完成任务，已完成任务不会再次分派，原提交和对话记录保留。
