# AI 助手与生成介绍

站点启用 AI 后，可以让助手查询词条、梳理关系、核对公开资料，或按你的要求提交修改。助手使用当前账号的权限；聊天不会额外申请 API Key 或 MCP 授权。

## 查询与编辑

登录后从顶栏打开「AI 助手」（`/assistant`），选择站点提供的模型，描述问题或修改要求。页面的「问答」「自备 API」「用量记录」分别管理会话、连接和消耗。可以直接附上词条链接、编号和来源，例如：

```text
查询 UMCK-1766 对应发行版，说明发行主体、收录内容和关联作品。
如果发行资料缺少我提供的官方来源中的编号，请核对当前记录后补充；不要改作品或发行版的原始名称。
```

查询会读取当前目录和关系，外部来源只作为资料。编辑在服务器工作副本中进行，多次操作可形成 commit，再按你的指令 push，不再逐次询问授权。普通账号发起 PR，有免审权限的账号可直接合入；来源与查证记录可省略。查看助手返回的实际提交和合入结果，回答文字不能代替状态。

模型可能理解或引用错误。原始来源、结构化记录和修订历史仍用于核对事实；AI 的回答本身不能充当录入来源。助手不会因为资料缺少封面、署名或评分而要求先补齐整个词条。

## 积分与 token 用量

使用站点提供的 API 时，按模型的输入、输出 token 费率消耗积分。一次问答可能包含多轮查询和模型调用，显示的用量是本次请求累计值。调用前会预留积分，结算后释放未使用的部分；余额不足或平台预算用尽时停止新的调用。

输入框底部直接选择模型并显示同一个积分余额。未配置自备 API 时不显示连接选择器。上下文指示包含当前系统提示、已保存会话、未发送的输入和工具定义，使用与运行时一致的保守估算上界；可展开查看消息、工具数量和回答预留量。它描述当前上下文，不是多轮调用累计的计费 token。

积分来自：

- 注册赠送：首次访问 AI 账户时发放，每个账号一次。
- 编辑采纳：奖励生效时间之后，已批准或免审且实际应用的提交，每个提交一次；待审、拒绝和未应用的提交不发放。
- 管理员调整：后台带说明增减积分，保留流水。

赠送数量和模型费率由站点配置。当前不提供赞助支付或自动充值。平台预算以美元成本管理，用户积分是独立额度，两者没有固定兑换关系。

用量记录包括输入、输出和缓存输入 token、扣除积分及调用状态。若上游超时或中断后无法确认实际消耗，记录为 `unknown`，并以 `usage_estimated=true` 标明保守估算；这不表示调用成功，也不应直接重复发送同一修改。

## 使用自己的 API（BYO）

在助手的 API 凭据管理中添加名称、公开 HTTPS API 根地址和密钥。当前接入支持 OpenAI 兼容的 Chat Completions 协议；根地址应包含服务商要求的版本路径，例如 `https://provider.example/v1`。默认使用所选站点模型的上游模型名，也可在 BYO 凭据中填写自己的上游模型名；输入上下文与最大输出仍受所选站点模型的 token 上限约束。

配置自己的凭据后，模型旁会出现可选的「自备 API」选择器；选择后不消耗积分和平台 API 预算，仍记录 token 用量，服务商可能按自己的规则计费。密钥加密保存，只显示是否已配置与末尾提示，可以改名、替换、停用或删除。管理员能管理凭据记录，不能通过列表读取完整密钥。

会话和用量记录保存在站点，模型提供方会收到本轮对话及完成请求所需的资料。不要把不需要处理的秘密填进提问或来源内容。

## 词条中的生成介绍

词条正文区域可选择基于结构化资料生成介绍，生成按所选模型费率消耗积分，自备 API 由服务商计费。已有有效缓存时直接读取，不重新调用模型，也不重复扣费；访问页面不会自动花费积分生成新内容。

生成内容可以包含说明文字、关系与字段表格、时间轴和数据图。表格、时间轴和数据图由服务端从公开结构化事实生成，说明文字由模型生成。每份内容保留来源条目与生成信息。资料范围被截断时会标明不完整。

缓存会校验条目、邻接关系与引用实体、definitions、语言和模型配置的事实指纹。资料变化后不会继续把旧内容作为当前介绍，可重新生成。使用站点 API 生成的介绍可共享读取；使用 BYO 生成的缓存仅对本人显示。生成介绍不会覆盖人工维护的正文或直接新增目录事实。

## Wikipedia、萌娘百科与公开来源

助手和 MCP 可以读取站点配置的公开来源及 MediaWiki API，保留原文、抓取时间、内容哈希、署名和许可说明。Wikipedia、萌娘百科或自定义站点的可用性由其公开接口决定；访问被拒绝时显示失败，不绕过限制。

外部百科内容不会自动覆盖词条。需要录入其中的事实时，仍通过工作副本与提交录入，并遵守来源的署名和许可要求。网络请求及 MCP 参数见[云端 MCP](/api-mcp)，程序接入见[AI 助手 API](/api-assistant)。
