# 社区使用指南

社区讨论支持匿名阅读。登录后可按账号权限发起话题、回复、写短评和收藏词条。

## 浏览与发帖

从导航栏进入社区，按板块、话题标签和关键词查找讨论。板块名称与开放情况以当前站点显示为准：

- **站点公告**：查看站务通知。
- **求助答疑**：询问使用与编目问题。
- **考据评注**：讨论来源、版本差异与资料核验。
- **反馈与建议**：报告缺陷或提出改进建议。
- **闲聊杂谈**：日常交流。

发起话题时选择合适板块，填写清楚的标题和正文。讨论某个作品时关联其词条，方便其他人查看资料。进入话题后可以回复和引用楼层；作者可删除自己的内容，管理员按权限处理违规内容。

## 条目短评与收藏

短评在词条详情页发布，适合围绕该条目展开简短讨论。需要长篇考据或多人讨论时，可另开话题并关联词条。

收藏可用于保存想再次查看的条目。设置页的隐私选项可控制收藏列表是否公开，默认公开；关闭后其他人看不到列表和收藏数量，本人仍可查看。公开列表仍按访问者的词条可见性过滤，不会因收藏而公开不可见的条目。

## 私信与通知

从用户主页进入私信会话，收件箱列出最近的会话和未读数量。私信只对参与者可见，读取会话与标记已读分别处理。

收件设置可以控制是否接受陌生人的新会话。遇到骚扰时使用对方主页的举报入口。相关 API 契约见[社区与互动 API](/api-community)。

站内通知提示回复、编目审核和相关活动。通知属于当前账号，可在通知页面阅读和标记已读。

## 举报与申诉

在实体、资源、短评、帖子或用户主页使用「举报」，选择原因并补充说明和证据链接。举报内容不会像普通帖子一样公开。

可以在「我的举报」查看处理进度。被处置方对结论有异议时，可按页面提示提交一次申诉；采纳申诉本身不会自动恢复已经删除的内容。

版权相关问题请同时参考[版权与 DMCA](/copyright)。

## 讨论规范

围绕事实讨论，尊重不同观点。引用资料时给出可以核验的出处；请勿发布骚扰、人身攻击、广告、灌水或侵权内容。

普通使用问题可公开求助，包含隐私或权属证明的内容请通过举报渠道提交。其他联系方法见[联系方式](/contact)。
