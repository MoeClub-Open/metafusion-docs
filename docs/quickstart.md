# 快速上手指南

先找一个你熟悉的作品。浏览公开词条不需要账号，找到资料后再决定是否参与编辑或社区讨论。

## 1. 找到作品

在首页或探索页输入作品原名、常见译名或创作者姓名。结果较多时，按实体种类和标签缩小范围。

同名结果可能对应不同作品或发行版。打开词条后核对创作者、内容简介、编号和发行资料，再确认是不是你要找的条目。

## 2. 看懂词条

| 页面内容 | 可以了解什么 |
| --- | --- |
| 基本资料与多语言名称 | 作品或主体的身份、简介与别名 |
| 创作与参与关系 | 作者、演唱者、角色、原作或续作 |
| 内容目录与表达 | 章节、篇目、译本、录音或剪辑 |
| 发行与收录 | 版本、分盘、曲目及内容出处 |
| 提交与修订记录 | 谁修改了什么，以及资料的历史版本 |

不同词条会显示适用的内容区块。想进一步分辨作品、录音和发行版，阅读[元数据目录教程](/catalog)。

## 3. 下载可用资源

词条有资源时，使用页面提供的下载入口。平台提供原始文件，播放和阅读由你自己的客户端完成。

公开词条绑定的文件可以匿名读取；其他文件是否可访问取决于词条可见性与账号权限。遇到访问问题，先查看[资源上传与下载](/upload-download)或[常见问题](/faq)。

## 4. 登录与个性化

登录页会说明当前是否开放注册，以及是否需要邀请码。注册并登录后，可以按账号权限编辑、互动或上传。

首页的「自定义推荐」可调整分区顺序与显隐；可用的个性化功能以界面为准。标签筛选会匹配所选标签中的任意一个。

## 5. 提交第一次修改

1. 先搜索原名、译名和外部编号，确认没有重复条目。
2. 现有词条有错误时，从详情页进入编辑；需要新词条时使用「新建条目」进入编目入口。
3. 填写能核实的资料，暂时不确定的内容留空。
4. 保存到工作副本，可以继续编辑多个条目，再用修改说明创建 commit。
5. push 后，免审账号直接合入，其他账号发起 PR；合并后回到详情页核对结果。

来源与查证记录可省略。多人同时修改时，先回读差异、解决冲突，再推送，不会用自己的旧副本覆盖他人的新内容。

协作与命名说明见[词条编辑与审查规范](/editing-guide)。投稿文件前请阅读[资源上传与下载](/upload-download)。
