# 平台概览

MetaFusion 是一个由社区共同维护的开放元数据目录，收录动画、音乐、影视、文学、游戏等作品，以及它们的版本、创作者和相互关系。每个词条有稳定的地址与修订记录，方便查阅、引用和补充。

## 你可以做什么

- **找作品和创作者**：按名称搜索，用标签和首页分区发现相关内容。
- **弄清版本区别**：查看普通版、限定版、译本、录音或剪辑的资料，分辨每次发行实际收录了什么。
- **沿着关系继续探索**：从作品找到参与者、原作、续作或相关企划。
- **补充资料**：登录后在工作副本中编辑，可以把多次操作形成提交，再直接合入或通过 PR 协作。
- **访问原始文件**：有可见资源绑定时下载原档；文件访问权限与元数据浏览分别判定。
- **接入自己的工具**：开发者与 Agent 可以通过 API 查询公开数据，并在获得授权后提交修改。

## 一个简单例子

一首歌曲可以有原唱和翻唱录音。同一份录音又可能出现在单曲、专辑和精选集里。

MetaFusion 分别记录「歌曲是什么」「哪一份录音」「哪一次发行收录了它」，这样可以比较版本，也能找到同一内容的不同出处。你无需先学习全部模型就能浏览；编辑时再参考[元数据目录教程](/catalog)。

## 浏览、登录与权限

公开词条可以直接浏览和搜索。社区互动、编辑、上传等操作需要登录，能否使用某项功能由账号权限决定。注册是否开放、是否需要邀请码由当前站点设置决定，登录页会显示提示。

未发布的词条只对创建者及具有相应管理权限的人可见。原始文件按绑定词条的可见性和存储权限提供访问；详情见[资源上传与下载](/upload-download)。

## 维护原则

- **按事实分层**：作品、表达与发行各自记录有来源的事实；简单作品不必凑齐所有层级。
- **保留依据与未知**：提交说明表达改动意图，来源可补充；资料冲突时说明分歧，无法确认时留空。修订历史帮助后续贡献者核对变化。
- **区分资料和文件**：元数据可以独立建立，提供文件前需确认权利；文件读取按资源权限判定。
- **围绕事实协作**：命名、分类或版权有争议时附来源讨论，通过社区和举报渠道处理，尊重贡献者。
